# Server API Files

Upload these PHP files to your hosting (e.g. `https://hallmarkpro.in/mahalaxmi/`):

| File | Purpose |
|------|---------|
| `get_jobs_api.php` | Get pending requests, update job numbers, weights, HUID codes |
| `save_job_api.php` | Save job cards and HUID data |
| `check_jobs_api.php` | Check if jobs exist |
| `manage_jeweller_api.php` | Manage jeweller data |

**Single source**: These are the only copies. Do not duplicate in other folders.
